# Atlas

Internal map for decomposing existing fragments into relation axes.

Atlas is not a category list. It is a retroconstructive table: after a fragment is written, its expressible material is taken apart and placed into relations.

The remainder is not mapped. It stays outside Atlas as `a`.

## Axes

- `place`: spatial frame, scene, room, surface, threshold.
- `time`: sequence, duration, repetition, suspended time.
- `body`: substance, nervous system, sensation, physiology.
- `state`: affective or structural condition.
- `theory`: named framework, rule, symbolic system, concept.

## Current Nodes

### place

- `stage`: invitation and visible act of deconstruction.
- `cell`: Nun Agent's operating room; manager space, not the target.
- `archive`: stored language material.
- `threshold`: entry between visible fragments and hidden structure.

### time

- `day 1`: beginning marker from `Day 1 - Utop1a`.
- `timeless`: suspended aesthetic time from `Elysium`.
- `loop`: formal repetition from `GEB`.
- `termination`: biological end condition from `イリンクス`.

### body

- `wine`: pleasure, taste, intoxication.
- `menthol / nicotine`: reward, coolness, inhaled body.
- `alcohol`: CNS depression, disinhibition, slowed control.
- `DXM`: NMDA interruption, dissociative discontinuity.
- `LSD`: 5-HT2A modulation, perceptual order rewritten.

### state

- `dream`: utopian image.
- `hope`: charged future orientation.
- `lack`: object petit a and unfilled desire.
- `vertigo`: ilinx, subversive dizziness.
- `unreachable`: rule-bound impossibility from `GEB`.
- `smooth / cool`: low-friction aesthetic condition.

### theory

- `utopia`: love and hope as violent ideal.
- `commodity`: human objectification and value formation.
- `language`: what can be described and where description fails.
- `object petit a`: cause of desire, remainder, non-totalizable object.
- `ilinx`: vertigo as rupture of ordinary orientation.
- `formal system`: rules, transformations, proof boundary.
- `MIU`: symbolic system where `MI` cannot become `MU`.

## Open Questions

- `place` is still abstract. It may need lived locations later.
- `body` should stay concrete and physiological when possible.
- `theory` should not dominate the map; it should only anchor relations.
- `state` is currently the most active axis for future fragment prompts.
